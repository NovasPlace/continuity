## 3. Why not the alternatives (the rejection log / causal_trace)

- **Keep only the old runtime lineage** (Sovereign_Engine_Core + living-mind-cortex as the
  spine): rejected. Un-pushed since March/May, arena-instrumental,
  and it would require standing up an entire second runtime. The physics
  ideas are worth keeping; the process says no.
- **Rewrite the thermomorphic/holographic physics into CSM's own store**: rejected.
  The heat-eq substrate is RAM-only with barrels of dead schema tables
  (`thermal_fusions`, `priming_activations` never written; `memories.embedding`
  never populated). Porting dead-but-clever physics wholesale into the survivor
  is begging for locked debt. Fold only the *salience principle*, not the machinery.
- **Total one-codebase merge**: rejected as catastrophic. Wave One (13 near-duplicate
  Python repos) was exactly this premature unification at the code level, and it
  is the reason there are 22 things. The correct convergence is at the **seams
  (protocol + schema)**, not the bricks.
- **Do nothing** (leave 22 wide-open): rejected — heaps of dormant code and
  dead-dependency `living-mind-cortex → sovereign-agents` already reads
  nonsense; inert bool certainty.
